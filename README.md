## Static Site Generator

A system that create static site by taking a markdown file and turning it into an html according to a template. 

This is made using Python with guidance from boot.dev in my path to learn more about os interaction with Python.

The static website can be accessed through: https://dramaniako.github.io/static_site_generator/


## How to Clone and Run it Locally
```
git clone https://github.com/Dramaniako/static_site_generator.git
./main.sh
```

## How to Build the Static Site
```
./build.sh
```

## How to Test the Functions
```
./test.sh
```
